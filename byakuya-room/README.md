# 白夜的小房間

在純白的 3D 房間裡陪伴白夜。白夜是渡川市的神明，會飄浮、發光，用表情、光和動作回應你。

## 直接觀看或發布

`index.html` 已包含完整的 3D 程式和樣式。可以在電腦上直接雙擊開啟，也可以上傳到 GitHub Pages 的發布目錄，讓讀者直接點網址觀看。讀者無須安裝 Node.js、啟動本機服務或執行任何指令。

要上傳現成網站，解壓 `byakuya-room-static.zip`，把裡面的 `index.html`、`.nojekyll` 和授權文件放進你的 GitHub Pages 發布目錄即可。發布目錄需要是儲存庫中已設定的 Pages 來源。網站入口也能放在儲存庫子路徑，沒有依賴電腦上的絕對檔案路徑。

源碼 ZIP 裡的根目錄 `index.html` 也是現成的網站入口；`room.source.html` 和 `src/` 則供修改程式使用。不要只把 `room.source.html` 當成發布入口。

## 修改源碼與預覽

需要 Node.js 22.12 或以上版本，或 Node.js 20.19 或以上的 20.x 版本。

```sh
npm ci
npm run dev
```

打開終端機顯示的本機網址，加上 `/room.source.html` 可觀看會隨源碼更新的開發預覽。手機與電腦使用同一套介面。

## 和白夜互動

| 操作                         | 白夜的反應                             |
| ---------------------------- | -------------------------------------- |
| 直接輕點白夜                 | 接觸處微微收攏，表情逐漸變得好奇       |
| 手指或滑鼠慢慢摸，短距離移動 | 接觸附近柔柔地回應，心情放鬆           |
| 捏住一小塊，輕輕拖動         | 只有接觸附近跟著手移動；放開後慢慢恢復 |
| 手機兩指分別接觸、輕拖       | 兩個接觸位置各自局部變形               |
| 手停在身上、輕摸一會         | 白夜自己慢慢靠近依偎；手離開後慢慢退回 |
| 小小熊／放下熊，或點公仔     | 把公仔交給白夜，或放回灰色坐墊         |
| 關燈／開燈                   | 房間照明慢慢變化，白夜持續發光         |

不需要先選摸摸、捏捏或抱抱模式。電腦的手停留是滑鼠停在白夜身上；手機是手指持續接觸。較大的局部拉動不會觸發依偎，安靜輕摸約兩三秒才會靠近。

灰色坐墊放在旁邊：寬方形、圓角、有厚度和細微布紋。白夜平常自由飄浮；疲倦或安靜待一段時間後，會自己移到坐墊上抱著小小熊休息。精神回復後又會飄起。直接碰牠時也會離開休息姿態。

快速反覆切燈會讓白夜皺眉。停下來、摸摸或抱抱可以安撫牠。牠不會被甩出去，不會撞牆，也沒有拖動後的飛出慣性。

鍵盤也可以操作：先用 Tab 選到白夜，Enter 戳戳、按住空白鍵讓白夜依偎，放開後退回；方向鍵摸摸。按鈕可用 Tab 和 Enter 操作。

白夜不會說話。偶爾出現的文字是這次互動網站設計的心聲，不是原作新增的正式台詞。

## 建置與自行放到 GitHub

```sh
npm run test
npm run build
```

`npm run build` 會建置 3D 程式，接著自動把程式和樣式內嵌進根目錄與 `dist/` 的 `index.html`。修改源碼後，重新建置再發布這份入口。可以依 [Vite 官方部署說明](https://vite.dev/guide/static-deploy.html#github-pages)安排自動建置；也可以直接上傳已提供的靜態版本。

直接開啟版使用同一份建置結果，只有發布方式不同，互動與角色設定相同。內嵌入口保留 Three.js 授權；靜態 ZIP 也另外附上授權文件。

`.gitignore` 已忽略 `node_modules/`、`dist/`、環境變數、日誌和暫存資料。請保留 `package-lock.json`，讓安裝版本一致。原始小說文件與參考插圖沒有放進專案。

## 實作

使用 Three.js、Vite、原生 JavaScript 與 WebGL 2。白夜以多層不規則柔光、自訂局部形變著色器、連續變化的手繪表情和柔和回復動畫呈現；回彈是受限制的視覺形變，沒有可把牠投擲出去的剛體物理。網站不需要後端、登入或付費 API，沒有雲端保存。重新整理會回到初始狀態。

需要支援 WebGL 2 的瀏覽器。開啟瀏覽器硬體加速會有較好的效果。手機觸控手勢已實作；實機效能仍需要用你讀者常用的手機確認。

如果瀏覽器支援 WebMCP，網站會提供與一般互動共用的摸摸、依偎、燈光和小小熊工具。不支援時，所有一般互動仍可使用。
