# 白夜互動網站製作計畫

這個網站讓讀者在安靜的白色房間裡陪白夜待一會。使用者可以溫柔地摸、戳、搓、捏和拉白夜，牠則用光、表情和飄浮動作回應。設計以你提供的設定、#26〈踏進渡假村的我們〉、#27〈踏遍白砂的我們，還有光〉及三張插圖為依據。

## 角色設定

白夜是渡川市的神明。牠會飛、略帶透明、能飄浮；體型固定，不說話。從故事可確認，牠的光溫暖但不燙手，喜歡被抱與被摸，也會主動蹭人。玩一整天後，牠會變暗、移動變慢；受到溫柔的擁抱和撫摸時，光又會恢復。

小小熊是時葉借給白夜的公仔。白夜可以用光裹住牠；累了時可能抱不穩。#27 結尾，牠把小小熊交回時葉保管。網站依你的選擇加入這隻公仔，讓白夜可以抱著休息。

原作有吃蛋糕、泡水、玩小鴨與線香花火的片段。這一版的重點是房間裡的陪伴與柔軟形變。形變機制和文字心聲是互動網站的演繹，並不把它們當成故事已經確認的能力或正式台詞。

## 房間與外觀

房間保持純白，以淡淡的空間光線、微亮的地板和地板上的光暈呈現深度。關燈後，房間變暗，白夜持續發光。開關切換有平滑的光線過渡，避免整個畫面猛烈閃爍。

白夜保留插圖中的深色小眼睛和小嘴。身體改用多層柔光，輪廓鬆散、不規則，逐漸融進空氣。白光沒有球體表面的明確反光或硬殼邊界。眼睛的開合、彎度，以及嘴巴的曲線會連續變化。

房間旁邊放一張寬方形灰色地板坐墊，有厚度、圓角和柔軟布紋。白夜自由飄浮，累了或想歇一會才過去；小小熊可以留在坐墊上，休息時則由白夜抱著。

## 互動與情緒

| 互動   | 動作與反應             | 限制                               |
| ------ | ---------------------- | ---------------------------------- |
| 戳戳   | 驚訝、短暫縮一下       | 不會受傷或飛出去                   |
| 摸摸   | 瞇眼，精神與光回復     | 動作緩慢、柔和                     |
| 搓搓   | 隨來回動作開心回應     | 太久會疲倦                         |
| 捏捏   | 接觸附近柔柔地收攏     | 最大變形量有限                     |
| 拉拉   | 捏住的局部跟著手移動   | 中心保持飄浮，不跟著甩動           |
| 放開   | 彈簧回彈               | 回復原本大小，沒有投擲慣性         |
| 抱抱   | 輕摸停留後主動靠近依偎 | 可安撫不高興的情緒                 |
| 小小熊 | 用光抱著，或放回坐墊   | 疲倦時姿態更鬆、更低               |
| 開關燈 | 房間照明變化           | 約 2.6 秒內切換 4 次，白夜會不開心 |

情緒包含安靜、開心、有精神、驚訝、疲倦、難過與不開心。情緒與精神影響光的強弱、閃動節奏、表情和移動速度。安靜休息可以恢復精神；摸摸和抱抱能安撫牠。沒有飢餓、死亡、分數、登入或未回訪的懲罰。

偶爾出現一小段心聲，例如「2810回來了沒有呢……」或「想出去玩……」。心聲不會一直刷出來，也不會播放語音。文字可在 `src/main.js` 調整。

## 裝置與操作

手機與電腦共用 Pointer Events。手機可以單指操作，也可以用雙指在白夜身上輕捏；電腦使用滑鼠。取消摸、捏、拉與抱的模式按鈕。輕碰、短距離撫動、局部拖拉和停留，直接在白夜身上進行。位移很小的溫柔接觸維持兩三秒後，白夜自行靠近；接觸離開後慢慢退回。較大的局部拖拉暫停依偎。

所有主要按鈕提供足夠的觸碰範圍與鍵盤焦點。支援減少動態效果的系統偏好。分頁離開前景後停止推進情緒與精神，返回時不會一下子變累。

## 技術與交付

使用 Three.js 的 WebGL 2 顯示、透明著色器與受限制的彈簧回彈。技術依據：[Three.js WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)、[ShaderMaterial](https://threejs.org/docs/pages/ShaderMaterial.html)。採用 Vite 建置，再將樣式與完整程式內嵌成 `index.html`。GitHub Pages 的讀者直接點網址就能載入，無須安裝或執行任何指令；本機也能雙擊同一份入口。

交付包括完整源碼、鎖定依賴版本的 `package-lock.json`、`.gitignore`、操作說明、角色與互動計畫，以及建置好的靜態網站 ZIP。這次只在本機製作與預覽，你會自行上傳 GitHub。

## 驗證

檢查日夜畫面、手機與電腦尺寸、戳摸捏拉、抱抱、小小熊、快速切燈的情緒與安撫。狀態測試確認普通切燈不會累積成惱怒、疲倦後可恢復、局部拉動不影響遠處、放開回復、表情持續變化、依偎需要溫柔停留、休息與喚醒，以及無效互動不會改變角色。實際手機的觸控手感與效能仍留待實機試玩調整。
